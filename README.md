# 🎓 CollegeAlert

CollegeAlert is a modern Android application designed to keep students informed about important college activities, announcements, events, alerts, and deadlines in one convenient place.

## ✨ Features

- 📢 College Alerts
- 🎉 Upcoming Events
- 📅 Important Dates & Deadlines
- 📋 Announcements & Notices
- 🔍 Easy-to-use interface
- 🎨 Modern Material 3 UI
- 📱 Student-friendly design

## 🛠️ Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- MVVM Architecture
- Coroutines
- State Management
- Navigation Compose

## 🎯 Purpose

The purpose of CollegeAlert is to provide students with a centralized platform where they can quickly access important college information instead of relying on scattered notices or communication channels.
